# トミュライブ（tomyu-live）リニューアル方針

ブランド表記は日本語「トミュライブ」、英字「tomyu-live」。

白 #ffffff、ピンク #ec347c、イエロー #ffeb70、ライラック #e9e0fa、パープル #7052ad、本文 #30283a。

日本語には端末のヒラギノ・游ゴシック・メイリオを使用。大きな日本語見出しが主役。英語の手書き風の短文は、少量のアクセントとしてGeorgiaのイタリックを使用。

トップは左にメッセージと応募ボタン、右に傾いたライブ画面と人物写真。写真やコメントから、配信の楽しさを伝える。スマートフォンではメッセージ、応募ボタン、配信イメージの順で縦に配置。

ロゴだけのメインビジュアルと装飾のグラデーションをやめ、人物とライブ配信の文脈を中心に設計。サポート内容、可能性、所属フロー、FAQ、応募へと進む。実在しない所属ライバーや架空の実績は掲載しない。

報酬・特典はバックアップの記載に基づき、最新の適用条件は公式LINEで案内。出典画像: image-46.png（100%還元）、image-47.png（Pococha特化）、image-48.png（マネージャー制）、image-49-fixed-2.png（ボーナス）、image-59.png〜image-63.png（所属の流れ）。
