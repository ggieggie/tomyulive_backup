# トミュライブ デザイン改訂

## 参照

- https://321.inc/ : 日本語の大きな見出しに専用書体を使い、人物の写真を主役にする構成。公式ソースの `.midashi` は `a-otf-midashi-go-mb31-pr6n`。書体そのものや写真は転載せず、本文と見出しの役割分担を参考にする。
- https://one-carat.com/ : キービジュアルの大胆な文字サイズ、人物を中心にした情報の優先順位を参考にする。配色・コピー・実績は流用しない。

## 方針

ユーザーが選んだ方向性は、ポップなファッション誌のような構成。前案で好評だった明るさを残し、装飾を減らして文字と写真の力を強める。

色は白 #ffffff、ピンク #e6256d、ローズ #fce8ef、ライラック #d6c5ec、文字 #29242c。黄色を重ねた飾りやドット柄をやめ、ピンクをブランドの主色として絞る。

日本語はZen Kaku Gothic New（500/700/900）。本文は500、見出しは900。細いシステムフォントや過度な字詰めを避け、行間と改行位置で文字のまとまりを作る。英数字はBarlow Condensedの700をロゴと数字に限定。Google Fontsの公式リポジトリから取得し、ライセンスを添えてWOFF2で同梱する。ビルド・閲覧時の外部フォント取得は不要。

構成は、左に大きな日本語の見出し、右に大きな矩形の人物写真。続いて事務所紹介、サポート、活動の可能性、所属フロー、FAQ、応募。基本は左揃え。スマホでは写真→見出し→応募という一般的な順にせず、見出しと応募ボタンを先に見せ、写真はその下で大きく扱う。

```text
logo          nav                 LINE
-------------------------------------
大きな日本語見出し     | 写真
説明・応募             | 写真
-------------------------------------
Pococha特化 / マネージャー制 / 初期費用無料
-------------------------------------
事務所について     紹介文
サポート           内容の異なる3項目
活動の可能性       進め方 / FAQ / 応募
```

前案の見直し: 斜体の英語、星・ハート、架空のライブ操作UI、傾いたスマホ風枠、繰り返しの丸いカード、装飾的なチケットを削減する。単に角丸をなくすのではなく、大きな写真と日本語の見出しに記憶の中心を移す。

## ユーザーの追加指示

簡素化しすぎた案は却下。ポップなファッション誌風をより強く、文字・写真の重なり、凝ったグラフィックや立体オブジェクト、大胆な色面を入れる。ブランド名は英字 `tomyu-live`、日本語「トミュライブ」を厳守する。NYLON JAPAN (https://www.nylon.jp/magazine) とViVi (https://www.vivi.tv/) の誌面・情報の組み方も調べる。

その後の画像への不評を受け、画像の採用判断は保留。どの素材への指摘かを確認し、未確認のまま人物写真や立体素材を追加しない。

## 最終フィードバック（優先）

女性の写真は「可愛い」と評価されており、継続使用する。却下対象は生成したヘッドホン単体とハートの立体オブジェクト。これらの立体画像をサイトに入れない。女性写真に対する不評という先の解釈は誤り。

採用する方向: 太い日本語の見出しを、写真・大胆な英字のディスプレイ文字・紙のステッカー・特色インクのような色面と重ねる、ポップなファッション誌風。新しいオブジェクトはサイト固有のSVGグラフィックとして制作し、立体ヘッドホン／ハートは使わない。背景や角丸を削るだけの簡素な案に戻さない。

## 初案と雑誌テイストの調整

追加依頼「これにさっきのテイストを足してよ」に対応。初案の白・ピンク・ライラック・黄色、アーチ状の配信写真、丸いバッジ、配置と余白を継承。Zen Kaku Gothic New の太い日本語見出しと Barlow Condensed の英字、黄色の手描き下線、コメントのマスキングテープ、小さなラベルのみを追加した。独立したヘッドホン・3Dハート画像、重い黒枠、全面コラージュは再導入していない。調整は refinements.css にまとめた。


## デザインの入れ直し（2026-11-02）

ユーザーが選んだ方向は「今の配色のまま上質に」。白・ピンク・ラベンダー・黄の配色と女性の写真（アーチ型の枠）、太い日本語の見出しと黄色の手描き下線は継続した。refinements.css は globals.css に統合し、スタイルを1ファイルで作り直した。

- 減らしたもの: Hello!、星・アスタリスク、ハート＋1、Be yourself!、吹き出し、偽のコメント入力欄、英語の流れる帯、Scroll to discover。
- ヒーローの飾りは LIVE の札・コメント1つ・黄色い丸バッジの3つに絞った。
- 英語の流れる帯は、要点の帯（報酬還元率100%・初期費用0円・Pococha特化・LINEで相談）に置き換えた。100%には「対象範囲・支払い方法は所属前に説明」の注記を付けた。
- 本文の「好き」の例を色付きの札で見せ、サポートは番号付きカード、はじめ方は線でつないだ4ステップにした。
- 下層ページの見出しは、パンくずにページ名、右上に線だけの二重アーチ（ステージの形）を置いた。
- 最後の申し込み欄はピンクの面にして白いLINEボタンを置き、フッターは濃い色で締めた。
- 改行: 見出しは `\n`（必ず改行）と `|`（必要なときだけ改行）で文節単位に折り返す。Chrome では FAQ とボタンも文節で折り返す（word-break: auto-phrase）。
- 本文は 16px（スマホ 15px）、色を濃くして読みやすくした。
- Tailwind の `container` と名前がぶつかるため、幅の枠は `wrap` に変えた。
- 運営会社の情報は、ユーザーの判断で今回は載せていない。
